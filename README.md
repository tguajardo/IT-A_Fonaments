# Fonaments

## Overview

This repository contains the exercises, assignments, and projects developed during the **Fonaments** stage of my programming studies.

The goal of this stage was to build a solid foundation in software development by learning computational thinking, problem-solving, algorithms, and object-oriented programming using Python.
